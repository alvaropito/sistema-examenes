Configurador de Examen Seguro

Convierte tu formulario de Google Forms en un examen blindado contra cambios de pantalla, listo para GitHub Pages o uso local sin instalar nada.

1. Datos del Examen

Pega cualquier enlace de tu Google Form. El sistema lo adaptará para embebido automáticamente.

2. Supervisión del Navegador

Genera un PIN aleatorio y compártelo por separado del enlace. Es una clave compartida, no una identidad de estudiante.
Coloca 0 para tiempo ilimitado. El reloj usa la hora del navegador y no es un límite verificable por el servidor.
Infracciones: presionar Alt+Tab, salir de pantalla completa o cambiar de pestaña.
  • Pantalla Completa forzada al inicio
  • Detección instantánea de pérdida de foco (Alt+Tab / Windows)
  • Bloqueo de Clic Derecho e Inspeccionar Elemento (F12)
  • Bloqueo de atajos de copia y pegado (Ctrl+C, Ctrl+V)
  • Cifrado en memoria: la URL del Formulario no viaja en texto plano
